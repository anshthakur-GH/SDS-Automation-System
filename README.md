# SDS Automation System

This repository contains automated scripts for processing, converting, and analyzing Safety Data Sheets (SDS).

## Features
- Convert PDF SDS documents to formats like Word (DOCX).
- Clean and normalize chemical tables and safety info.
- Generate specialized cover pages and headers.
- Extract logos, text, and tables from SDS documents.
- Batch processing support.

## Usage
Ensure you have the required dependencies installed (e.g. `PyMuPDF` (`fitz`), `python-docx`).
Place your target SDS documents in the appropriate folder and run the batch conversion scripts.
